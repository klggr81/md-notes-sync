# Security

If you find a security problem in md-notes-sync, please don't open a public issue. Report it privately instead:

- on GitHub: **Security** tab > **Report a vulnerability**, or
- by email: info@klggr.de

Please describe what you found and how to reproduce it. You'll get an answer within a few days.

Fixes go into the newest version only. To update: tray menu > **About** > **Check for updates**.
